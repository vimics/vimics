Send a case

Upload the CT and tell us about the patient. A Vimics engineer reviews the data and replies by email.

vimics.vet/dicom
  1. 01

    Export the CT as DICOM

    Export the complete series, all slices, from your CT workstation or PACS. A ZIP file is fine. You can remove the owner's name before export.

  2. 02

    Upload the files

    The upload page is a Vimics folder on Microsoft OneDrive. You do not need an account.

    Upload DICOM files

    Please name the ZIP file as Clinic_Patient_Species, for example AnkaraVet_Max_Dog.zip.

  3. 03

    Send the case details

    Email the details below to info@vimics.vet, using the same name as the ZIP file in the subject line.

    Clinic:
Surgeon:
Patient (species, breed, age, weight):
Region and indication:
What you need (guide, implant, planning, model):
Planned surgery date, if known:
    Write the email

  4. 04

    We get back to you

    We review the CT and reply by email with our questions or a proposal for the case.
